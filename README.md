# Hermes Agent Server

Docker Compose setup for running [Hermes Agent](https://hermes-agent.nousresearch.com) by NousResearch,
including the API gateway and web dashboard.

## Services

- **hermes** — OpenAI-compatible API gateway on port `8642`
- **hermes-dashboard** — Web dashboard on port `9119`

Both services share the same data volume at `~/.hermes` on the host.

## Prerequisites

- Docker Engine 24+ with Compose v2
- At least 1 GB RAM (2 GB required for browser automation)
- An API key for at least one supported LLM provider

## Quick Start

### 1. Initialize configuration

Run the setup wizard once to generate `~/.hermes/.env` with your API credentials:

```bash
docker run -it --rm \
  -v ~/.hermes:/opt/data \
  nousresearch/hermes-agent setup
```

### 2. Configure environment

Copy the example file and adjust as needed:

```bash
cp .env.example .env
```

### 3. Start services

```bash
docker compose up -d
```

The gateway will be available at `http://localhost:8642` and the dashboard at `http://localhost:9119`.

## Configuration

All options are set via `.env` in this directory. Copy `.env.example` to get started.

| Variable | Default | Description |
|---|---|---|
| `TZ` | `Asia/Taipei` | Container timezone |
| `HERMES_IMAGE` | `nousresearch/hermes-agent:latest` | Docker image tag |
| `HERMES_DATA_DIR` | `~/.hermes` | Host path for persistent data |
| `HERMES_GATEWAY_PORT` | `8642` | Gateway port on the host |
| `HERMES_DASHBOARD_PORT` | `9119` | Dashboard port on the host |
| `HERMES_MEMORY_LIMIT` | `4G` | Memory limit for the gateway container |
| `HERMES_CPU_LIMIT` | `2.0` | CPU limit for the gateway container |
| `GATEWAY_HEALTH_URL` | `http://hermes:8642` | Gateway URL used by the dashboard health probe |
| `GATEWAY_HEALTH_TIMEOUT` | `3` | Health probe timeout in seconds |

> **Note:** API keys (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`) are written to
> `~/.hermes/.env` by the setup wizard, not this file. Do not commit them here.

## Data Volume Structure

The volume mounted at `~/.hermes` (or `HERMES_DATA_DIR`) contains:

- `.env` — API credentials (generated by setup)
- `config.yaml` — Agent configuration
- `sessions/` — Conversation history
- `memories/` — Persistent memory store
- `skills/` — Installed skills

> **Warning:** Never run two gateway containers against the same data directory
> simultaneously. Session files and memory stores do not support concurrent writes.

## Browser Automation

When using browser-based tools (Playwright/Chromium), uncomment `shm_size` in
`docker-compose.yml` and ensure the host has at least 2 GB of RAM:

```yaml
hermes:
  # ...
  shm_size: "1g"
```

## Resource Requirements

| Resource | Minimum | Recommended |
|---|---|---|
| Memory | 1 GB | 2–4 GB |
| CPU | 1 core | 2 cores |
| Disk | 500 MB | 2+ GB |

## Common Commands

```bash
# Start all services in the background
docker compose up -d

# Follow logs
docker compose logs -f

# Stop all services
docker compose down

# Update to the latest image
docker compose pull && docker compose up -d
```

## Troubleshooting

- **Browser tools fail** — Uncomment `shm_size: "1g"` and ensure at least 2 GB RAM is available.
- **Permission errors on data dir** — Run `chmod -R 755 ~/.hermes`.
- **Container exits immediately** — Check logs with `docker logs hermes` for invalid `.env` or port conflicts.
- **Dashboard shows gateway as unreachable** — Verify `GATEWAY_HEALTH_URL` points to the correct host and port.
